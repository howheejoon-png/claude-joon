How a review works

  1. Describe the enhancement and set the threshold.
  2. Paste each piece of evidence: test classes, production classes, the JaCoCo XML report, JUnit results and the git diff or changed-file list. Paste as many times as needed.
  3. Review the dashboard: every finding shows what was observed, why it matters and where in the evidence it comes from.
  4. Copy the report as formatted text or as a table for Excel.

Handling of pasted code

  • Runs entirely in this browser tab; the page's security policy blocks all network connections.
  • Nothing is stored: no browser storage, no cookies. Closing the tab discards the session.
  • Pasted Java and XML are only read as text — never executed or rendered as HTML.
  • The clipboard is only written when you press a copy button, and never read.
